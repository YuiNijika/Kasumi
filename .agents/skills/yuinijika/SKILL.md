# YuiNijika

本 skill 只负责加载线上规则，不保存编码规范与文档规范正文。

开始任何编码或写文档任务前，直接只读浏览以下地址：

`https://blog.miomoe.cn/docs/skill/yuinijika.mdx`

线上地址以 `.mdx` 结尾并直接返回 Markdown。线上页面包含：

- 编码规范（格式、命名、类型、结构、复杂度守则、注释、语言重点）
- 文档规范（页面骨架、内容纪律、示例要求、检查清单）

加载后继续遵守项目 `AGENTS.md`。
